# godot project
 
This project aims to implement a two-player tabletop zero-sum battle game named Spellcaster by using the Godot engine. In this game, you need to play the role of a mage and fight against another mage through hand gestures.

## Project structure
asset: Stores the resource files required for the game, such as pictures, audio, etc. \n
scenes: Stores the scene files of the game, where each scene represents a specific part of the game, such as players, summoned items, menus, etc.  
scripts: Store the script files of the game, which are used to control the game logic, character behavior, etc.   
global: Stores the global auto-loaders of the game. These auto-loaded nodes or scripts are automatically loaded when the project starts and remain available throughout the project's runtime.  

## Development environment
Godot engine version: This project is developed based on Godot 4.3. It is recommended to use Godot 4.x for normal operation and subsequent development.  
Operating system: Windows or macOS is recommended.  
Development tools: You can use the built-in editor of Godot for development, or you can use Code editors that support GDScript or C#, such as Visual Studio Code, etc.    

## Usage method
Run the game: Open the project in the Godot editor and click the Run button to start the game. The game can also be exported as an executable file and run on the corresponding platform.\n
Modify the game: If you want to modify or expand the game, you can open the project in the Godot editor and modify the resource file, scene file or script file as needed.
